# Data access

## Newly generated data

Mouse colon bulk RNA-seq data generated for this study have been deposited in the NCBI Gene Expression Omnibus under accession **GSE349603**.

GEO page: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE349603

The record is currently scheduled for public release on 3 January 2028. In accordance with GEO policy, it must be released earlier if the accession is quoted in a publicly available manuscript, preprint or thesis.

## Data excluded from this repository

FASTQ files, BAM files, H5AD/RDS objects, FCS files, microscopy images and other large or controlled source files are not stored in GitHub. Public inputs should be obtained from GEO or Zenodo. Newly generated bulk RNA-seq files should be obtained from GSE349603 after release or through reviewer access supplied by the authors.
